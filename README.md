En este rol me enfoqué en optimizar y automatizar el flujo de carga hacia el WMS, el cual requería ingresar manualmente entre 1.000 y 1.500 facturas diarias.
Para solucionar este cuello de botella, coordiné con los proveedores del sistema y desarrollé una solución externa para consolidar los datos mediante archivos CSV. El flujo extrae el detalle de las facturas diarias, clasifica los productos por categorías y genera una carga masiva unificada al WMS, lo que permite segmentar y distribuir eficientemente las tareas al equipo de picking.
Adicionalmente, implementé una funcionalidad para exportar hojas de trabajo en PDF por categoría, integrando cálculos automatizados para el control y validación durante el despacho.

Impacto y resultados:
Reducción del 25% en la tasa de errores de despacho, al clarificar la distinción entre unidades de empaque secundarias (cajas) y primarias (paquetes/unidades), facilitando además la curva de aprendizaje del personal nuevo.
Mayor trazabilidad y agilidad en el picking, eliminando tiempos muertos operativos y optimizando la asignación de pedidos en bodega.
